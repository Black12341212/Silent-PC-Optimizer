# Silent PC Optimizer v5.0

Умная утилита для автоматической оптимизации Windows с полноценным GUI, мониторингом, игровым режимом и 30+ функциями.

## Что нового в v5.0
- Вкладка **Updates** — просмотр, блокировка/разблокировка и откладывание обновлений Windows
- Вкладка **Disks** — список дисков, тип (SSD/HDD), здоровье (SMART), TRIM и дефрагментация
- Вкладка **Processes** — управление приоритетом процессов в реальном времени
- **Встроенный апдейтер** — проверка новой версии на GitHub из трея
- **Точка восстановления** — создание перед оптимизацией (настройка `auto_restore_point`)
- **Импорт/экспорт настроек** на вкладке Settings
- **Поиск по настройкам**
- **Авто-тема** — следование теме Windows (`auto_theme`)
- Исправлены многочисленные баги (температура, сетевые/дисковые скорости, потокобезопасность истории, корзина, гибернация и др.)

## Возможности

### Очистка системы
- Очистка TEMP, TMP, корзины, кэша браузеров
- Очистка DNS-кэша, Prefetch, кэша миниатюр, кэша шрифтов, кэша Windows Update
- Автоматическая очистка при превышении порога RAM

### Мониторинг и аналитика
- Мониторинг CPU, RAM, Disk, Network с графиками в реальном времени
- Мониторинг температуры CPU (через WMI/OpenHardwareMonitor)
- История оптимизаций с статистикой за день/неделю/месяц
- Мониторинг сетевого трафика по процессам
- Алерты при критической нагрузке (Email/Telegram)

### GUI с вкладками
- Панель (Dashboard) с текущими метриками
- Мониторинг с графиками CPU/RAM/Disk/Network
- Оптимизация — кнопки для всех операций очистки (+ точка восстановления)
- Службы Windows — просмотр, включение/отключение
- Автозагрузка — управление программами автозагрузки
- Деинсталлятор — удаление установленных программ
- Системные утилиты — SFC, DISM, информация о системе
- Бенчмарк — тест CPU/RAM/Disk с оценкой
- Безопасность — очистка следов, сканирование Defender
- Шифрование — AES-256 шифрование файлов
- Игровой режим — освобождение ресурсов
- Updates — управление обновлениями Windows (блокировка/откладывание)
- Disks — здоровье дисков, TRIM/дефрагментация
- Processes — приоритеты процессов
- Режим стриминга — приоритизация OBS/браузеров
- Режим презентации — отключение уведомлений
- История — лог всех оптимизаций
- Настройки — все параметры в одном месте (поиск, импорт/экспорт)
- О программе

### Тёмная/светлая тема
- Переключение темы из трея или настроек

### Управление службами
- Автоматическое отключение ненужных служб (SysMain, Windows Search, Print Spooler и др.)
- Ручное управление через GUI

### Оптимизация SSD/HDD
- TRIM для SSD, дефрагментация для HDD
- Информация о здоровье диска (SMART)

### Планировщик задач
- Интервальная или ежедневная оптимизация по расписанию

### Горячие клавиши
- `Ctrl+Alt+O` — быстрая оптимизация

### Управление автозагрузкой
- Просмотр и отключение программ из реестра и папки автозагрузки

### Деинсталлятор
- Список установленных программ с удалением

### Проверка целостности системы
- Запуск SFC /scannow, DISM restorehealth

### Управление обновлениями Windows
- Откладывание и блокировка автоматических обновлений

### Шифрование файлов
- AES-256 шифрование/дешифрование через встроенный менеджер

### Игровой режим
- Автоматическое освобождение ресурсов при запуске игр

### Оптимизация для стриминга
- Приоритизация сетевого трафика для OBS, Twitch

### Режим презентации
- Отключение уведомлений на время презентации

### Бенчмарк
- Тест производительности CPU/RAM/Disk с результатами

### Очистка следов
- Удаление истории браузеров, недавних файлов, логов Windows

### Проверка на вирусы
- Интеграция с Windows Defender для быстрого сканирования

### Защита процесса
- Опциональная защита от случайного закрытия

## Установка и запуск

```bash
git clone https://github.com/Black12341212/Silent-PC-Optimizer.git
cd Silent-PC-Optimizer
pip install -r requirements.txt
python main.pyw
```

## Сборка EXE

```bash
build.bat
```

Результат будет в папке `dist/`.

## Зависимости

- `psutil` — мониторинг системы
- `pygetwindow` — управление окнами
- `pystray` — иконка в трее
- `Pillow` — генерация графики
- `pywin32` — Win32 API
- `keyboard` — горячие клавиши

## Конфигурация

Все настройки хранятся в `settings.json`. Также доступны через GUI (вкладка "Настройки").
