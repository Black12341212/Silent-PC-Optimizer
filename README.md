# Silent PC Optimizer v3.0

Тихая утилита для автоматической оптимизации Windows. Управление через системный трей, настройка через JSON, логирование, график RAM.

Работает тихо, потребляет минимум ресурсов и "просыпается" только когда вашему ПК нужна помощь.

## Возможности

### Автоматический режим
Мониторит загрузку RAM каждые 30 секунд (настраивается). Если память забита больше порога (85%):
1. Очищает TEMP с фильтром по возрасту (только файлы старше 24ч) и расширениям (.tmp, .log, .cab и др.).
2. Сворачивает фоновые окна браузеров (Chrome, Firefox, Edge, Opera, Yandex).
3. Отправляет уведомление о результатах (сколько ГБ освобождено).

### Системный трей
Иконка в области уведомлений с информацией о текущем использовании RAM.
- **Оптимизировать сейчас** — ручной запуск очистки.
- **Авто-режим** — включение/выключение автоматического мониторинга.
- **Автозапуск** — добавление/удаление из папки Startup Windows.
- **Статистика RAM** — график использования RAM за последние 30 минут.
- **Завершить тяжёлые процессы** — остановка фоновых процессов с высоким потреблением RAM.
- **Язык** — переключение между Русским и English.
- **Справка** — О программе + ссылка на поддержку проекта.

### Конфигурация (settings.json)
Все настройки вынесены в JSON-файл рядом с программой. Генерируется автоматически при первом запуске.

Ключевые настройки:
- `ram_threshold` — порог RAM для запуска оптимизации (по умолчанию 85%).
- `check_interval` — интервал проверки в секундах (по умолчанию 30).
- `browser_names` — список браузеров для сворачивания.
- `temp_cleaning` — фильтры очистки TEMP (возраст, расширения).
- `clean_recycle_bin` — очистка корзины (выкл. по умолчанию, требует прав админа).
- `clean_browser_cache` — очистка кэша браузеров (выкл. по умолчанию).
- `background_process_killer` — завершение тяжёлых процессов с белым списком.
- `hibernation` — планировщик гибернации при неактивности и высокой RAM.
- `language` — язык интерфейса (ru/en).

### Безопасная очистка
- Удаляет только файлы старше 24 часов (настраивается).
- Фильтрует по расширениям (.tmp, .log, .cab, .txt, .dat, .cache, .old, .bak).
- Пропускает заблокированные файлы.
- Очищает `%TEMP%` и `%TMP%` (если это разные папки).

### Очистка дополнительных папок (опционально)
- Корзина (`$Recycle.Bin`) — выкл. по умолчанию.
- Кэш браузеров (Chrome Cache, Firefox cache2, Edge Cache) — выкл. по умолчанию.

### Завершение фоновых процессов
Завершает процессы с потреблением RAM выше порога (по умолчанию 500 МБ). Белый список системных процессов в конфиге.

### Планировщик гибернации
Если RAM превышает порог и пользователь неактивен N минут — ПК уходит в гибернацию. Уведомление за 10 секунд перед гибернацией. Выключена по умолчанию.

### Логирование
Все действия записываются в `logs.log` с ротацией (максимум 5 МБ, 3 бэкапа).

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Black12341212/Silent-PC-Optimizer.git
   ```
2. Установите библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
3. Запуск:
   ```bash
   python main.pyw
   ```

При первом запуске создастся `settings.json` с настройками по умолчанию.

## Сборка .exe

Для сборки в один .exe файл:
```bash
build.bat
```
Или вручную:
```bash
pyinstaller --onefile --windowed --name "Silent PC Optimizer" main.pyw
```

Готовый .exe будет в папке `dist/`.

## Зависимости

Проект написан на Python и использует:
- `psutil` — мониторинг системы.
- `pygetwindow` — управление окнами.
- `pystray` — создание иконки в трее.
- `Pillow` — генерация графики и графика RAM.
- `pywin32` — автозапуск и очистка корзины.

├── settings.json             # Конфигурация (генерируется автоматически)
